Make the catalog's "Highest rating" sort confidence-weighted (sends-aware) so the
default list surfaces proven climbs. Observed on the phone right after installing the
Boardsesh-sourced catalog v2 (2026-10-20): the top of the default list was all
"★ 5.0 / 5" climbs with only 1–3 sends, so a perfect score from one or two climbers
outranks a well-tested 4.6. The older three-star catalog had the same weakness; the
finer 0–5 scale makes it more visible. Today's workaround is the Minimum sends filter
(e.g. 20). Andrew likes the idea; the ranking approach (for example a Bayesian /
minimum-evidence weighting) is a product choice to settle when scoped.
