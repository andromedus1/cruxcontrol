Import climbs Andrew previously built in the Kilter app from screenshots that show
the climb marked on the board with Kilter's hold colors. CruxControl should use the
screenshot to identify the selected holds and their colors, allow the interpreted
climb to be reviewed and corrected, and then save it in CruxControl's durable climb
library.
