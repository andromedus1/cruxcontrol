# Keep animations running with the phone screen off

Andrew wants to explore whether the native app, now replacing the PWA for phone
use, can keep board animations running when the phone screen is turned off.
Capture this as a possible native-app capability for later; feasibility and
platform limits are not yet established. Do not interrupt the current Kilter
statistics-filter work to implement it.
