# Capacitor Community — Bluetooth Low Energy

## Anchored observations (paraphrased)

### Installation / iOS; Platform Support

The plugin documents iOS and Android support for discovery, connecting, disconnecting, characteristic reads/writes, writeWithoutResponse and notifications. iOS setup requires a Bluetooth usage description; background use requires additional configuration. The README says Bluetooth is unavailable in its iOS simulator path and requires a real device. These are plugin capabilities, not proof of any particular board protocol, firmware or write pacing.
