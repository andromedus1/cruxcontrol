# Capacitor — Cross-platform Native Runtime for Web Apps

## Anchored observations (paraphrased)

### Introduction / Get Started

Capacitor offers a native container for web applications on iOS and Android and can be added to an existing modern JavaScript project. Its plugin API connects web code with native Swift/iOS and Java/Android functionality. The overview describes capability, not compatibility of every browser API or an application's measured performance.
