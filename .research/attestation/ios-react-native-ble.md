# React Native BLE PLX

## Anchored observations (paraphrased)

### About this library / Configuration & Installation

The library documents BLE scanning, peripheral connections, service/characteristic discovery, reads/writes and notifications, including an iOS background mode. It excludes Bluetooth Classic and peripheral mode. Its Expo instructions require custom native code rather than Expo Go. The README's compatibility table is limited; it does not establish compatibility with every current React Native/Expo release.
