# Capacitor Firebase Authentication plugin

## Compatibility and native authentication FAQ

The compatibility table lists plugin 8.x with Capacitor 8.x or later as actively supported. Native authentication uses native SDKs; signing in there does not automatically sign in the WebView's JavaScript Firebase SDK. Additional integration is needed for web-layer authentication.

## Supported methods and API

Native providers include Google and GitHub. Email/password and other methods are also documented. The API exposes the current user and ID token and supports a Firebase emulator. Android exposes pending authentication results. This documentation describes capabilities, not a completed build or a security assessment of the token persistence implementation.
