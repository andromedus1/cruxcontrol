# R2 Workers API

## Anchored observations

**R2PutOptions and R2Conditional:** R2 puts accept conditional-operation options, custom metadata and an integrity checksum, including SHA-256. A single hashing algorithm is supplied per operation. Conditional options include etagMatches and etagDoesNotMatch.
