# React Native — Core Components and Native Components

## Anchored observations (paraphrased)

### Native Components / Core Components

React Native builds Android and iOS applications using React and native platform capabilities. Its core components create platform views; View and Text are mapped to native views and presented alongside web analogues such as div and paragraph. React familiarity does not make a DOM component a native component.
