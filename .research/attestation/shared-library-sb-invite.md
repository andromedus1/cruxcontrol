# Supabase JavaScript — inviteUserByEmail

## Summary

The Auth admin API provides an email invitation operation.

## Anchored observations (paraphrased)

### Invite a user by email
The operation sends an invite link to the specified email address. The email parameter is required.

### Example
The documented JavaScript call is `supabase.auth.admin.inviteUserByEmail(email)`. The method belongs to the admin API; the page does not itself define group authorization, a contribution data schema, or an application's invitation-management interface.
