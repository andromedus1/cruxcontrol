# cloudflare/pages-action — deprecated in favor of wrangler-action

## Summary

The `cloudflare/pages-action` GitHub Action repository is officially deprecated. Its
README directs users to migrate to `cloudflare/wrangler-action`, which supports Pages
deployments and offers a unified tool for managing both Workers and Pages. This is the
load-bearing source for "use wrangler-action, not pages-action" in any CI deploy
recommendation.

## Key passages

> which supports Pages deployments and offers a unified tool for managing both Workers
> and Pages."
