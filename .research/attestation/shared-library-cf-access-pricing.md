# Cloudflare — Pricing, workspace security plans

## Summary

The workspace-security free plan includes a bounded user allowance.

## Anchored observations (paraphrased)

### Platform: Free; Usage & Support: User Limit
The free workspace-security plan is listed at USD 0 and the comparison gives a limit of 50 users. The pay-as-you-go plan is listed at USD 7 per user/month. These workspace-security prices are distinct from Workers runtime pricing.
