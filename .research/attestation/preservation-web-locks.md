# Web Locks API

## Anchored observations

**Shared and exclusive locks:** The specification defines shared and exclusive locks and callbacks holding a lock until their returned promise settles. Multiple shared holders may coexist; an exclusive holder excludes other holders of the same name within the lock manager scope.
