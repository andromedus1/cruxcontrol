# Google Drive application data

## Anchored observations

**Application folder / constraints:** The application data folder is hidden from the Drive UI and other apps. The drive.appdata scope is non-sensitive. Users can delete the folder; removing the app from My Drive deletes its application folder. Files there cannot be shared, moved across spaces or trashed. This folder is distinct from Drive's reserved device-backup folder.
