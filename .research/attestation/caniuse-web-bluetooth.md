# caniuse.com — Web Bluetooth support table

## Summary

Browser support data for the Web Bluetooth API as of mid-2026. Global support is
~77%. Supported in Chromium-family browsers — Chrome (56+), Edge (79+), Opera
(43+), Samsung Internet (6.2+). NOT supported in Firefox (all versions) or Safari
on macOS/iOS (all versions). The API lets sites communicate over GATT with
nearby user-selected Bluetooth devices.

## Key passages

- Global support: "77.22% + 0% = 77.22%".
- Supported: Chrome (version 56 and later), Edge (version 79 and later), Opera (version 43 and later), Samsung Internet (version 6.2 and later).
- Not supported: Firefox (all versions through 154), Safari (all versions through TP), Safari on iOS (all versions through 26.5).
- "Allows web sites to communicate over GATT with nearby user-selected Bluetooth devices in a secure and privacy-preserving way."
