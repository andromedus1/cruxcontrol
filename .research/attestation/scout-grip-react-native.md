# Grip Connect React Native platform

## Anchored observations (paraphrased)

### Introduction / Usage / Requirements / Example app

The package wraps the core API with `react-native-ble-plx`, retaining the core
connect/notify/stream shape. The documentation covers permissions and native setup,
requires a physical device, and states that Expo Go does not include the BLE module.
It links an Expo example as a project-setup and BLE-usage reference. This documents
an alternative adapter implementation path, not a cross-framework benchmark.
