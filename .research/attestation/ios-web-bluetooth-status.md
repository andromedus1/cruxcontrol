# Web Bluetooth — Implementation status

## Anchored observations (paraphrased)

### Safari

The implementation-status document lists Safari as unsupported. It separately notes that a third-party iOSWebBLE Safari extension can polyfill the API through CoreBluetooth; that is user-installed native bridging, not WebKit support. The original WebBluetoothCG URL redirected to this WHATWG repository during acquisition.
