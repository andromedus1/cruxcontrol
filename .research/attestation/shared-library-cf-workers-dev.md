# Cloudflare Workers — workers.dev

## Summary

Workers supplies a configurable subdomain without first onboarding a custom domain, with a documented personal/hobby positioning.

## Anchored observations (paraphrased)

### Opening description; Configure workers.dev
A Workers account comes with a configurable workers.dev subdomain. Workers receive a URL in the form worker-name.account-subdomain.workers.dev; onboarding a custom domain is not required to start.

### Production qualification
The page recommends a route or custom domain for production. It describes workers.dev as a Free website intended for personal/hobby projects that are not business-critical.

### Manage access to workers.dev
An enabled workers.dev URL is public by default. Access can require authentication for deployment, preview, and version URLs; policies select who is allowed. A provided hostname alone does not make the service private.
