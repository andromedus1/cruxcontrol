# Cloudflare Access one-time PIN

## Anchored observations

**Log in with OTP / behavior and limits:** The user visits the protected application and enters an email address. Access sends a code when policy permits that address. Codes are single-use and expire ten minutes after the initial request. Valid code entry redirects to the application. Mail filters can interfere.
