# Supabase email delivery

## Anchored observations

**Default SMTP restrictions:** The bundled SMTP service is for non-production use and sends only to pre-authorized project-team addresses. The page documents changeable rate limits and no delivery/uptime SLA for the default service; general application email authentication requires suitable delivery configuration.
