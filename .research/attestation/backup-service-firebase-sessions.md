# Firebase Authentication sessions

## Manage User Sessions

Sign-in exchanges credentials for an ID token and a refresh token. ID tokens last one hour. The refresh token obtains new ID tokens; documented expiry conditions include deleting or disabling the user and major account changes such as email or password updates. The page also describes administrative refresh-token revocation. Long-lived sessions therefore remain revocable.
