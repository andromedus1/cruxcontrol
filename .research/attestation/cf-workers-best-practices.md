# Cloudflare Workers Best Practices — "Use Workers Static Assets for new projects"

## Summary

Cloudflare's official Workers Best Practices documentation states that Workers
Static Assets is the recommended way to deploy static sites, single-page
applications, and full-stack apps on Cloudflare, and that new projects should use
Workers instead of Pages. It explicitly notes that Pages continues to work but that
new features and optimizations are focused on Workers. This is the load-bearing
official-docs statement on Cloudflare's forward direction for static hosting — not a
deprecation of Pages, but a clear steer of new investment toward Workers.

## Key passages

> "Workers Static Assets is the recommended way to deploy static sites, single-page
> applications, and full-stack apps on Cloudflare. If you are starting a new project,
> use Workers instead of Pages. Pages continues to work, but new features and
> optimizations are focused on Workers."
