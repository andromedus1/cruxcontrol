# SQLite backup API

## Anchored observations

**Using the SQLite Online Backup API:** The page describes lock-coordinated copying, its blocking and interruption risks, and the Online Backup API for incrementally copying a live database to a snapshot. It also lists VACUUM INTO as a way to produce a separate live-database copy.
