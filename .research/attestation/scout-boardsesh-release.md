# Boardsesh App Store release history

## Anchored observations (paraphrased)

### Version history — 2.0, Jun 23

The developer describes version 2.0 as a native rewrite, claiming improved list
scrolling and search compared with prior lag. The note lists Bluetooth board
control and lock-screen/Live Activity functions. This is developer-authored release
copy on an App Store listing, not a controlled before/after benchmark or a diagnosis
of the old framework's intrinsic performance.

### Version history — 2.1.0, Jun 28 / 2.2.0, Jul 7

Subsequent notes report iPhone board-lighting fixes, recovery after Bluetooth
interruptions, an iOS sheet-interaction freeze fix, and steadier Bluetooth behavior.
The listing is evidence of distributed releases and reported fixes, not independent
verification of those fixes on other hardware.
