What to try

Use the buttons inside each screen. Try sign-in, search, an existing playlist, a new playlist, and the publish confirmation. The strip above each screen is review navigation, not proposed app navigation.

The ownership rule

Personal copies stay unchanged when a shared climb changes or disappears. Updates will be offered explicitly. This first preview covers finding, saving, and first publication; the update-review surface comes later.
